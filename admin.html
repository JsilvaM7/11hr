Configure o acesso ao GitHub

Para publicar no site e subir fotos, você precisa de um Token do GitHub. Só precisa fazer isso uma vez.

1. Acesse GitHub → Settings → Developer settings → Tokens (classic)
2. Em "Note" escreva: 11hr Admin
3. Em "Expiration" escolha: No expiration
4. Marque a caixa "repo" ✅
5. Clique Generate token e copie o código (começa com ghp_)
